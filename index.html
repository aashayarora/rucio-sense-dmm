Data Movement Manager

DMM is the interface layer between Rucio/FTS and SENSE in the Rucio–SENSE interoperation framework. It provisions SDN circuits for Rucio replication rules and divides link bandwidth between them, so HEP data flows move over network-aware paths.

Architecture reference → Daemons, data models, request lifecycle, the LP bandwidth optimiser, and the SENSE, Rucio and FTS integrations. Source on GitHub → Code, configuration samples, Dockerfile and the Helm chart.

Helm chart

This site is also DMM’s Helm repository. Create the configuration secrets first (etc/mksecrets.sh, see the README), then:

bash
helm repo add dmm https://aashayarora.github.io/rucio-sense-dmm
helm install dmm dmm/dmm
